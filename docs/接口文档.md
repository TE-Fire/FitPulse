# FitPulse 接口文档

> 项目代号：FitPulse  
> 版本：v1.0  
> Base URL：`http://localhost:8080/api/v1`  
> JDK：21 · 后端：Spring Boot 3.2.5 · 数据库：MySQL 8

---

## 一、基础约定

### 1.1 统一返回结构 `Result<T>`

所有接口响应均包裹在以下结构：

```json
{
  "code": 0,
  "message": "success",
  "data": { "..." },
  "timestamp": 1700000000000
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | Integer | 业务状态码，0=成功，非0=异常 |
| message | String | 描述信息 |
| data | T / null | 业务数据（data=null 的接口也会返回该字段） |
| timestamp | Long | 服务端毫秒时间戳 |

### 1.2 状态码 `ResultCode`

| code | 含义 | 典型场景 |
|---|---|---|
| 0 | 成功 | 正常返回 |
| 400 | 参数错误 | 必填缺失、格式不合法、长度越界 |
| 401 | 未登录 / Token 无效 | 未带 Authorization、Token 过期、签名错 |
| 403 | 无权限 | 非本人数据、角色越权 |
| 404 | 资源不存在 | ID 查不到、路径无效 |
| 409 | 业务冲突 | 用户名/邮箱重复、目标状态冲突 |
| 500 | 服务端异常 | 兜底未捕获错误 |

### 1.3 分页格式

**请求**（Query 参数）：
```
?pageNum=1&pageSize=20
```

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| pageNum | Integer | 否 | 1 | 从 1 开始 |
| pageSize | Integer | 否 | 20 | 1-100 |

**响应 data**（`PageResult<T>`）：
```json
{
  "total": 123,
  "pageNum": 1,
  "pageSize": 20,
  "pages": 7,
  "list": [ {} ]
}
```

### 1.4 鉴权

- **免鉴权接口**：`POST /auth/register`、`POST /auth/login`、`POST /auth/refresh`
- **其他所有接口**：请求头
  ```
  Authorization: Bearer <accessToken>
  ```
- Token 类型：JWT HS256
- 有效载荷 Claim：`sub=userId`、`username`、`iat`、`exp`
- accessToken：默认 24h
- refreshToken：默认 30d（存 Redis，注销可主动失效）
- 401 处理：前端调 `/auth/refresh` 换一对新 Token；refresh 失败 → 清空本地凭证 → 跳转登录页

## 二、认证模块 `/auth`

### 2.1 注册 POST `/auth/register`
鉴权：否

**请求体**

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| username | String | 是 | 3-32 字母数字 | 登录用户名（唯一） |
| email | String | 否 | RFC5322 格式 | 邮箱（唯一，可用于找回密码） |
| password | String | 是 | 8-64，至少含字母+数字 | 明文密码（服务端 BCrypt 存储） |

```json
{
  "username": "fire_dev",
  "email": "fire@fitpulse.local",
  "password": "Fire@2026"
}
```

**响应**：`data = null`
```json
{ "code": 0, "message": "success", "data": null, "timestamp": 1755410000000 }
```

> 常见 409：用户名重复 / 邮箱重复

---

### 2.2 登录 POST `/auth/login`
鉴权：否

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | String | 是 | 用户名（或邮箱） |
| password | String | 是 | 密码 |

```json
{ "username": "fire_dev", "password": "Fire@2026" }
```

**响应 data = LoginUserVO**

| 字段 | 类型 | 说明 |
|---|---|---|
| accessToken | String | 24h 访问令牌 |
| refreshToken | String | 30d 刷新令牌 |
| userId | Long | 用户 ID |
| username | String | 用户名 |

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIx...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIx...",
    "userId": 1,
    "username": "fire_dev"
  },
  "timestamp": 1755410001000
}
```

> 常见 400：密码错误（统一提示"用户名或密码错误"防枚举）

---

### 2.3 刷新 Token POST `/auth/refresh`
鉴权：否（请求体带 refreshToken，不入 Bearer）

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| refreshToken | String | 是 | 登录下发的 refreshToken |

```json
{ "refreshToken": "eyJhbGciOiJIUzI1NiJ9..." }
```

**响应**：同 2.2（返回一对新 Token + userId/username）

> 服务端会做刷新旋转：旧 refreshToken 在短时间内可重放一次，超时失效。

---

### 2.4 登出 POST `/auth/logout`
鉴权：是（Bearer accessToken）

**请求**：无 Body，无需参数

**响应**：`data = null`

服务端行为：
1. 从 accessToken 解析 userId
2. Redis 中删除该用户的 accessToken/refreshToken 缓存
3. 返回成功

## 四、训练模块 `/training`

### 4.1 动作库

#### 4.1.1 分页查询动作库 GET `/training/exercises`
**Query**

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| pageNum | Integer | 否 | 1 | — |
| pageSize | Integer | 否 | 20 | 1-100 |
| keyword | String | 否 | | 名称模糊匹配 |
| category | Integer | 否 | | 过滤：ExerciseCategory（1胸 2背…） |
| customOnly | Boolean | 否 | false | true=只查我自定义，false=系统+我自定义 |

**响应 data = PageResult&lt;ExerciseVO&gt;**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 动作 ID |
| name | String | 动作名 |
| category | Integer | ExerciseCategory |
| categoryName | String | 译文案（前端也可本地翻译） |
| difficulty | Integer | Difficulty 1-3 |
| muscleGroup | String | 主要肌群描述 |
| description | String | 动作要领 |
| imageUrl | String | 示范图 URL（可为空） |
| systemBuilt | Boolean | true=系统默认，false=用户自定义 |
| createdAt | String | 创建时间（yyyy-MM-dd HH:mm:ss） |

#### 4.1.2 新增自定义动作 POST `/training/exercises`
**请求体 = ExerciseSaveReq**

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| name | String | 是 | 1-50 | 动作名（同用户下不重复） |
| category | Integer | 是 | 1-8 | ExerciseCategory |
| difficulty | Integer | 是 | 1-3 | Difficulty |
| muscleGroup | String | 否 | ≤50 | 主要肌群（如胸大肌、肱三头肌） |
| description | String | 否 | ≤500 | 动作要领 |
| imageResourceId | Long | 否 | | 已上传文件ID（/file/upload 返回的 id） |

```json
{
  "name": "哑铃集中弯举",
  "category": 4,
  "difficulty": 1,
  "muscleGroup": "肱二头肌",
  "description": "坐姿单臂、肘部贴大腿内侧、慢下放",
  "imageResourceId": 12
}
```

**响应**：`data = { id }`（新建动作 ID）

#### 4.1.3 修改动作 PUT `/training/exercises/{id}`
- Path: `id`=Long
- 请求体：同 4.1.2 ExerciseSaveReq
- 权限：只能修改 systemBuilt=false 的自定义动作；系统动作返回 403

#### 4.1.4 删除动作 DELETE `/training/exercises/{id}`
- Path: `id`=Long
- 权限：只能删 systemBuilt=false；引用该动作的 workout_plan_exercise 关联记录一并软删除
- 响应 data=null

### 4.3 训练记录

#### 4.3.1 训练记录分页 GET `/training/records`
**Query**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum / pageSize | Integer | 否 | 默认 1/20 |
| startDate | String | 否 | `yyyy-MM-dd`，过滤 ≥ 该日期 |
| endDate | String | 否 | `yyyy-MM-dd`，过滤 ≤ 该日期 |

**响应 data = PageResult&lt;RecordListItemVO&gt;**

| totalSets | Integer | 组数（B） |

#### 4.3.2 提交训练 POST `/training/records`
> 提交成功后，看板的 B/C 维度统计会立即更新（因为基于此表聚合）

**请求体 = WorkoutRecordSubmitReq**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| planId | Long | 否 | 关联计划，可空=自由训练 |
| trainedAt | String | 是 | yyyy-MM-dd HH:mm |
| durationMin | Integer | 是 | ≥ 1 |
| notes | String | 否 | ≤500，备注 |
| sets | `[{exerciseId, setNo, weightKg, reps, rpe?}]` | 是 | 组明细数组，按顺序 |

```json
{
  "planId": 1,
  "trainedAt": "2026-08-16 19:30",
  "durationMin": 65,
  "notes": "今天状态不错，卧推加重2.5kg",
  "sets": [
    { "exerciseId": 1, "setNo": 1, "weightKg": 42.5, "reps": 10, "rpe": 8 },
    { "exerciseId": 1, "setNo": 2, "weightKg": 42.5, "reps": 10, "rpe": 8 },
    { "exerciseId": 1, "setNo": 3, "weightKg": 42.5, "reps": 8,  "rpe": 9 },
    { "exerciseId": 5, "setNo": 1, "weightKg": 15,   "reps": 12, "rpe": 7 }
  ]
}
```

**响应**：`data = { id, totalVolume, totalSets, totalReps }`（服务端回算，便于前端立即显示本次成绩）

#### 4.3.3 单次训练详情 GET `/training/records/{id}`
**响应 data = RecordDetailVO**

| 字段 | 类型 | 说明 |
|---|---|---|
| id / planId / planName / trainedAt / durationMin / notes / totalVolume / totalSets / totalReps | — | 与列表字段一致 |
| exercises | `[{exerciseId, exerciseName, exerciseImageUrl?, sets:[{setNo,weightKg,reps,rpe?}]}]` | 按动作聚合的明细 |
