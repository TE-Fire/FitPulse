# FitPulse 设计契约（冻结版）

> 本文件为 FitPulse 三端（后端 / Web管理后台 / Android客户端）统一开发契约，所有接口、字段、路由、表结构以此为准，修改需三端同步确认。

---

## 一、项目基础信息

| 项 | 值 | 说明 |
|---|---|---|
| 项目代号 | FitPulse | 健康健身一体化App |
| 架构风格 | 单体架构 (Monolith) | 个人使用，避免微服务复杂度 |
| 后端端口 | 8080 | Spring Boot 内嵌 Tomcat |
| API 统一前缀 | `/api/v1/**` | 接口版本化 |
| Web 管理后台端口 | 5173（开发） | Vite dev server，代理 `/api` → `:8080` |

| 文件存储 | MinIO（个人版可降级为本地文件目录） | 头像/动作图片/饮食照片等 |

## 二、数据库设计约定

### 2.1 命名与字段约定

- 表名、字段名：**小写 + 下划线**（snake_case）
- 主键：`id BIGINT`，使用 **雪花算法** 生成（MyBatis-Plus `IdType.ASSIGN_ID`）
- 逻辑删除：`deleted TINYINT DEFAULT 0`（0=正常，1=已删）
- 时间戳：`created_at DATETIME`、`updated_at DATETIME`，MyBatis-Plus 自动填充
- 金额/体重/容量等小数：`DECIMAL(10,2)`
- 状态字段：`TINYINT`，配合 Java 枚举

## 三、API 统一约定

### 3.1 统一返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { ... },
  "timestamp": 1700000000000
}
```

| code | 含义 |
|---|---|
| 200 | 操作成功（Result.success() 统一返回） |
| 400 | 参数错误 |
| 401 | 未登录 / Token无效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 业务冲突（如用户名重复） |
| 500 | 服务端异常 |

### 3.2 分页格式

**请求**：`GET /api/v1/...?pageNum=1&pageSize=20`

**响应** data：
```json
{
  "total": 123,
  "pageNum": 1,
  "pageSize": 20,
  "pages": 7,
  "list": [ ... ]
}
```

### 3.3 鉴权

- 登录接口 `/auth/login`、`/auth/register` 免鉴权
- 其他接口：请求头 `Authorization: Bearer <accessToken>`
- Token 结构：JWT（HS256），claim: `userId`, `username`, `iat`, `exp`
- accessToken 默认 24h，refreshToken 默认 30d
- 401 时前端调 `/auth/refresh` 续期；refresh 失败跳转登录

## 六、核心模块 API 接口清单

> 所有路径前缀 `/api/v1`，返回统一包裹 `Result<T>`。

### 6.1 认证模块 `/auth`

| 方法 | 路径 | 鉴权 | 请求 | 响应 data |
|---|---|---|---|---|
| POST | `/register` | 否 | `{email(@qq.com), password, code(6位数字注册验证码)}` | null（username由后端取邮箱前缀自动生成） |
| POST | `/register/send-code` | 否 | `{email(@qq.com)}` | null（6位数字注册验证码，5min有效，日志打印+QQ邮箱SMTP发送，60s限流） |
| POST | `/login` | 否 | `{email, type(1密码/2验证码), password?, code?}` | `{accessToken, refreshToken, userId, username}` |
| POST | `/login/send-code` | 否 | `{email}` | null（6位数字验证码，5min有效，日志打印+QQ邮箱SMTP发送；与注册验证码前缀完全隔离） |
| POST | `/refresh` | 否 | `{refreshToken}` | 同login（旋转失效旧refreshToken） |
| POST | `/logout` | 是 | — | null |

## 八、MinIO 文件目录约定

| bucket（或本地子目录） | 用途 | 命名示例 |
|---|---|---|
| `avatar` | 用户头像 | `{userId}/{yyyyMMdd}_{uuid}.jpg` |
| `exercise` | 动作示范图 | `{exerciseId}/main_{uuid}.jpg` |
| `food` | 饮食记录照片 | `{userId}/{yyyyMMdd}/{mealId}_{uuid}.jpg` |
| `general` | 其他 | `{yyyy/MM/dd}/{uuid}.{ext}` |

> 个人版降级为本地文件时，目录结构为：`${fitpulse.upload.path}/<bucket>/...`，返回URL为 `/files/<bucket>/...` 由 Spring MVC 静态映射提供。
